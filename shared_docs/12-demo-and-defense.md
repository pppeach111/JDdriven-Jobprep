# 12 演示、答辩与提交计划书

## 1. 核心叙事

不要以“我们实现了四个功能”开场。推荐叙事：

> 学生面对岗位时通常只能得到一个模糊匹配分，却不知道自己是否真的具备相应能力、差距如何验证、学习是否有效。职径以 JD 为目标，用能力—证据图谱把官方岗位发现、自适应测评、学习实践和简历更新连接成可验证闭环。

## 2. 60秒核心演示

### 0～10秒：输入

导入一个 Java 后端实习 JD 和一份演示简历，选择城市、毕业年份和可实习时间。

### 10～20秒：初始分析

展示：

- 硬门槛全部满足；
- 11项核心能力中7项可能满足；
- Redis 只有简历自述，Java 并发没有可靠证据；
- 系统没有直接给出无法解释的总分。

### 20～32秒：能力验证

完成一道 Redis 场景题。系统根据回答追问缓存一致性，随后将 Redis 从“L2，置信度35%”更新为“L2.7，置信度72%”，并给出回答引用。

### 32～42秒：学习闭环

系统将差距转为缓存改造实践，展示资料、预计6小时、产物、验收和复测。切换到预置的“已完成”演示用户，展示任务和压测结果如何提高证据可信度。

### 42～52秒：岗位发现

展示5个企业官方相似岗位，标注官网、最后核验时间、开放状态和硬门槛。点击按钮只跳转企业官网，不自动投递。

### 52～60秒：简历更新

展示如何将已验证实践转为一条带真实实验条件的简历候选，并强调所有内容由用户确认、不虚构经历。

## 3. 完整5～7分钟演示

1. 真实痛点和现有工具缺口：30秒；
2. 输入 JD、简历和求职约束：30秒；
3. JD要求、硬门槛、能力与证据图谱：60秒；
4. 自适应测评和动态追问：90秒；
5. 差距、学习任务、实践和复测：75秒；
6. 官方岗位发现与开放核验：60秒；
7. 证据化简历建议：45秒；
8. 架构、华为云和 CodeArts：45秒；
9. 数据指标、消融和限制：45秒。

## 4. 必须准备的演示数据

- 一份经过脱敏的 Java 后端 JD；
- 一份虚构但完整、事实一致的学生简历；
- 一个初始能力证据不足的用户状态；
- 一个已完成学习和复测的用户状态；
- 5～10个提前核验的官方岗位；
- 一组 Redis/Java 并发题目和稳定评分结果；
- 一个可复现的微型实践及测试数据；
- 原简历和证据化更新版本；
- 网络或模型失败时的备用录屏与本地数据。

演示数据必须明确标注，不要把预置结果伪装成现场刚完成的长任务。

## 5. 评委高概率追问

### 和直接问大模型有什么不同？

硬门槛由规则执行；岗位需官方来源和开放核验；能力判断融合多类证据并有置信度上限；学习完成后通过复测更新；大模型不能直接随意决定总分。

### 和招聘网站、AI简历工具有什么不同？

不做招聘平台库存和自动投递；以用户提供的目标 JD 为锚点寻找官方岗位；同一能力—证据图谱驱动测评、学习和简历，而非四个工具拼接。

### 如何证明能力测评可信？

采用明确分级锚点、混合题型、量表评分、实践证据和人工对照；结果是能力估计而非认证，同时展示一致性指标和失败样例。

### 如何证明岗位还可以投？

检查申请入口、截止提示、职位状态和页面有效性，记录最后核验时间和置信度；无法确认的岗位明确标记，不承诺绝对可投。

### 会不会侵犯招聘网站权益？

只采集公开企业官方岗位，不登录、不绕过验证码、不自动投递；遵守 robots、网站条款和访问频率，支持站点停用和数据删除。

### 简历生成是否会造假？

每条建议必须关联用户确认的事实或可复现实践。缺少证据时只请求补充，不生成数字或经历；最终保存由用户确认。

### 为什么不做语音？

语音是输入输出层，不能解决能力评价的可信度。初赛优先完成文本闭环，后续可在保持同一面试引擎的基础上接入语音。

## 6. 指标展示

不要只展示模型准确率，建议用一页表格呈现：

- 官方来源准确率；
- 岗位开放状态准确率；
- 硬门槛准确率；
- JD技能提取 F1；
- 开放题评分与人工一致性；
- 自适应测试平均题量节省；
- 任务可验收覆盖率；
- 简历无依据新增事实数；
- 用户完成时间和满意度。

同时展示2～3个失败案例及改进，通常比“全部99%”更可信。

## 7. PPT建议结构

1. 学生求职中的“知道岗位，却不知道真实差距”；
2. 产品目标和核心闭环；
3. 岗位—能力—证据图谱；
4. 官方岗位发现与核验；
5. 自适应测评和动态面试；
6. 差距驱动的学习、实践和复测；
7. 证据化简历；
8. 系统架构与华为云；
9. 数据集、实验和消融；
10. 应用价值、限制与下一步。

## 8. 提交前清单

- 在线地址可访问；
- 演示账号无个人隐私；
- 全新仓库和 Git 记录完整；
- README 能从零部署；
- 数据库和示例数据可初始化；
- 云服务配置有示例；
- 许可证与第三方依赖清晰；
- 数据来源和授权说明完整；
- CodeArts 使用证据已整理；
- 演示视频有字幕、无隐私、无长等待；
- PPT 中指标与报告一致；
- 现场和离线备用方案均已演练；
- 团队每人能解释核心算法和个人贡献。
