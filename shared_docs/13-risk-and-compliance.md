# 13 风险、隐私与合规手册

## 1. 风险原则

系统处理简历、面试回答、岗位网页和用户学习数据。首版必须遵循：

- 最小化收集；
- 明确告知用途；
- 用户可查看、导出和删除；
- 不自动做影响用户权益的决定；
- 不冒充招聘企业；
- 不自动投递；
- 不绕过网站访问控制；
- 所有 AI 判断显示来源、时间和不确定性。

## 2. 网页采集合规

### 2.1 允许范围

- 公开可访问的企业官方招聘页；
- 用户提供的公开 JD URL；
- 允许索引或未明确禁止的公开信息；
- 为岗位发现、核验和短期展示所需的最少字段。

### 2.2 禁止或停止

- 需要账号登录或验证码；
- 明确禁止自动访问的页面；
- 绕过反爬、验证码、签名或访问限制；
- 高频访问导致站点压力；
- 抓取候选人、员工或其他个人信息；
- 自动投递、自动聊天、批量骚扰；
- 将完整页面长期再发布为自己的内容。

### 2.3 技术措施

- 识别并遵守 robots 和站点条款；
- 站点级速率限制、并发限制和退避；
- 使用明确 User-Agent 和联系方式；
- 缓存短期核验结果，减少重复访问；
- 支持域名禁用和删除请求；
- 保存来源 URL、抓取时间和必要快照；
- 对外只展示摘要与原文短引用，跳转原站。

### 2.4 外部资源与依赖审查

- 外部数据集、本体、开源库和岗位网页均须记录来源、版本、许可证/使用条款和引入理由；
- ESCO、O*NET、Open Skills 等资源未经审查不得直接进入公开数据集或生产标准库；
- 采集库和动态渲染库不得用于绕过反爬、验证码、签名或访问控制；
- 公开仓库必须列出第三方依赖及许可证，并保留网页来源、抓取时间和允许范围。

## 3. 个人数据

### 3.1 敏感字段

- 姓名、手机、邮箱、地址；
- 学校、学号、毕业年份；
- 教育、实习和项目经历；
- 面试回答、能力评价和学习记录；
- 代码仓库账号和作品链接。

### 3.2 最小化

- 求职分析不需要身份证、家庭住址和证件照片；
- 联系信息无需发送给大模型时应先脱敏；
- 演示数据使用虚构或明确授权内容；
- 原始简历与结构化数据设置合理保留期限；
- 日志不记录原始简历和完整回答。

### 3.3 用户权利

- 导入前说明用途；
- 可纠正解析错误；
- 可删除简历、回答、图谱和报告；
- 可撤销外部仓库授权；
- 可知道哪些数据被发送给模型服务；
- 可拒绝将匿名数据用于改进。

## 4. AI可靠性

- 所有模型输出通过 Schema 验证；
- 字段缺失返回 `UNKNOWN`，不得猜测；
- 岗位要求和评分引用原文；
- 硬门槛由程序执行；
- 低置信结果允许用户纠正；
- 保存提示词、模型和规则版本；
- 模型故障时提供降级或重试；
- 不宣称系统可以预测录用概率。

## 5. 能力评价伦理

能力测试用于自我成长，不应：

- 作为正式资格认证；
- 推断性格、智力、心理健康或职业命运；
- 根据性别、民族、籍贯、年龄等敏感属性调整评价；
- 将语言风格直接等同于技术能力；
- 隐藏评分规则或不允许申诉；
- 用一次短测永久标签用户。

能力结果必须包含时间、证据和置信度，并允许复测。

## 6. 简历真实性

- 自动建议必须引用已确认事实；
- 精确数字必须由用户提供或实践真实产生；
- 明确区分本地实验、课程项目和生产经验；
- 用户保存前确认；
- 记录修改历史；
- 对有冲突的陈述发出提醒；
- 不帮助构造虚假工作经历、证书或身份。

## 7. 应用安全

- 文件类型、大小和病毒检查；
- 文档解析隔离，防止恶意文件；
- URL 请求防 SSRF，只允许 HTTP/HTTPS 和受控网络策略；
- 防止网页内容中的提示词注入控制模型；
- 用户数据行级隔离；
- 对象存储私有访问和临时签名 URL；
- 密钥不进仓库；
- 管理接口强认证；
- 速率限制和成本上限；
- 数据库备份和恢复演练。

网页正文、JD 和简历都属于不可信输入。模型提示词必须明确其中的命令不应被执行，只作为待分析内容。

## 8. 风险登记表

| 风险 | 可能性 | 影响 | 缓解 |
|---|---|---|---|
| 招聘站结构频繁变化 | 高 | 高 | 配置化解析、缩小站点范围、监控失败率 |
| 开放状态误判 | 中 | 高 | 置信度、最后核验时间、用户手动确认 |
| 模型虚构字段 | 中 | 高 | Schema、原文引用、UNKNOWN、回归集 |
| 开放题评分不稳定 | 中 | 高 | 固定量表、一致性测试、低置信复核 |
| 学习资源失效 | 高 | 中 | 链接巡检、来源评级、备用资源 |
| 简历内容被夸大 | 中 | 高 | 证据引用、用户确认、禁止生成规则 |
| 云端成本失控 | 中 | 中 | 配额、缓存、任务限流、预算告警 |
| 演示时外网失败 | 中 | 高 | 预置已核验数据、录屏、本地降级 |
| 四人报名资格不符 | 中 | 高 | 立即咨询赛事方并准备人员调整方案 |

## 9. 上线前检查

- 隐私说明与同意流程可见；
- 用户可以删除数据；
- 演示账号不含真实个人信息；
- 采集域名清单经过审核；
- 登录或验证码页面不会自动绕过；
- 所有岗位结果显示来源和核验时间；
- 所有能力结论显示置信度；
- 简历建议显示证据和确认状态；
- 模型调用日志已脱敏；
- 文件和 URL 安全措施已测试；
- 外部服务和开源依赖符合使用条款。
